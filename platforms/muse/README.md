# Muse Gadgets Adaptation

The Muse-format adaptation of the `tuya-smart-control` skill, submitted to Meta's open-source
[Muse Gadgets](https://github.com/facebookincubator/muse-gadget-sdk) project as
**Tuya Cloud Devices** ([PR #61](https://github.com/facebookincubator/muse-gadget-sdk/pull/61),
in review).

Notes:

- `SKILL.md` is a verbatim copy of the version submitted upstream. Relative links inside it
  (such as `../gadget-apple-homepod-mini/SKILL.md` and `home_link.md`) resolve within the Muse
  Gadgets repository layout.
- Once the upstream PR is merged, the directory in the Muse Gadgets repository becomes the
  authoritative copy; this directory remains as a stable reference for that submission.
- The canonical skill in this repository is still [`tuya-smart-control/`](../../tuya-smart-control/)
  at the repo root.
